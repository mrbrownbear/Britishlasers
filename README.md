# British Lasers Static Build

This repository contains a self contained static reconstruction of the British Lasers homepage.

All runtime CSS, JavaScript, fonts, logos, machine visuals and supporting imagery are stored inside this repository. The build does not depend on the source WordPress theme, Cloudflare challenge scripts, Google Site Kit, Formilla or remote media assets.

The page can be served by any static web server. Vercel routing is included so historical internal paths resolve to the local homepage instead of producing missing page errors.
